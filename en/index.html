NUMBER MEMORY TEST / DIGIT SPAN

How many digits can you remember?

Digits appear one at a time. When they disappear, type them back in the order you saw them. Each correct answer adds one more digit, until you find how many you can hold — your digit span. A simple short-term memory test.

View on the App Store

How it works

  1. Watch the digitsThey appear one at a time (0.7 seconds each by default).
  2. Type them backIn Backward mode, enter them in reverse order.
  3. Add a digitGet it right and the sequence grows by one digit. Miss the same length twice and the test ends — that length is your digit span.

Features

  • Two tests, Forward and Backward, each with its own personal best. Backward has you reorder the digits in your head, so it also uses working memory
  • When you miss, your answer is shown next to the correct one, with the wrong digits highlighted
  • See your daily personal best over time on the History screen
  • Change the starting length (2–12 digits) and how long each digit is shown (0.3–2.0 seconds)
  • Choose how digits are presented: Screen, Voice, or Both. Choose Voice to make it a listening test
  • Every digit is monospaced, on a clean, instrument-like screen
  • Records stay on your device. No sign-in

A typical adult forward span is said to be 7±2 digits (Miller, 1956). This app lets you check how many digits you can hold; it is not a medical diagnosis and is not intended to improve memory.

About ads

Ads appear at the bottom of the Home, results, and History screens, and when you tap Try Again on the results screen (every other time). No ads are shown while you watch the digits, type your answer, or see whether it was correct.
